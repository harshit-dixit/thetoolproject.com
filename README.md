# thetoolproject.com

Fast, clean, privacy-first web utilities and developer tools.

## 🚀 Live Site
Visit [thetoolproject.com](https://thetoolproject.com)

## ✨ Highlights
- **100% Client-Side:** Conversions and file processing occur entirely in the user's browser. Files are never uploaded to a server.
- **Fast & Responsive:** Built with modern web standards and optimized for sub-second interaction.
- **Accessible:** Semantic markup, high-contrast themes, and full keyboard navigation.

## 🛠️ Tech Stack
- [Astro](https://astro.build/)
- [TypeScript](https://www.typescriptlang.org/)
- Modern CSS & Web Workers

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harshit-dixit/thetoolproject.com.git
   cd thetoolproject.com
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
